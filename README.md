# Ao Redor do Mundo

Projeto acadêmico desenvolvido a partir do protótipo do Figma.

## Arquivos
- `index.html` — página inicial
- `detalhes.html` — página de detalhes dos destinos
- `autor.html` — página sobre a autora
- `style.css` — estilos do site

## GitHub Pages
Depois de enviar os arquivos para o GitHub:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
